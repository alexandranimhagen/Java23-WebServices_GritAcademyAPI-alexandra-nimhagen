Web Services – Grit Academy API

A Java-based web service project built as part of Grit Academy coursework. Demonstrates REST API development, HTTP handling, JSON processing, and backend architecture.

Features

- RESTful API endpoints for managing resources (e.g., students, courses)  
- Supports GET, POST, PUT, DELETE operations  
- JSON request and response handling  
- Input validation and error responses  
- Structured codebase with controllers, services, and models

Technologies Used

- Java  
- Spring Boot (or Jakarta EE/Servlet API)  
- Jackson or Gson for JSON serialization  
- Maven or Gradle  
- In-memory database (H2) or PostgreSQL/MySQL

How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/alexandranimhagen/Java23-WebServices_GritAcademyAPI-alexandra-nimhagen.git
Open in your IDE (IntelliJ, Eclipse etc.)

Build and run the application:


mvn spring-boot:run
or via main class

Test the endpoints using Postman, curl, or similar tool
